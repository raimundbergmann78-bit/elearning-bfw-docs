# BFW E-Learning – Vorschau

Statische Vorschau der E-Learning-Plattform für die Basisausbildung am BFW Nürnberg.

- Lernbereich mit den vier Ausbildungsbereichen als Kacheln
- Kategorieseiten mit Nuggets und Player
- Projektunterlagen und Checkliste als PDF – über die Kachel „Hoch, Hass, Bergmann“
- Verwaltung als Screenshot-Vorschau (Login, Kategorien/Nuggets, Upload)
- Präsentationsvideo: deutsch 7:59 Minuten, englisch 7:22 Minuten, mit Ton (Stand 26.11.2026)
- Quiz zur Präsentation: Fragen mit Antworten zum Wählen, farbig nach Teil (Hoch blau, Hass orange, Bergmann grün) – alle beantworten alle Fragen

Seite: https://raimundbergmann78-bit.github.io/elearning-bfw-docs/
Video: https://raimundbergmann78-bit.github.io/elearning-bfw-docs/video.html
Quiz: https://raimundbergmann78-bit.github.io/elearning-bfw-docs/quiz.html

Hinweis: GitHub Pages kann kein PHP/SQLite ausführen. Der Lernbereich und die Nuggets sind statisch nutzbar, die Verwaltung ist eine Vorschau.
